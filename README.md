# 🧪 Go Lab (go-lab)

> A hands-on laboratory and playground for experimenting with and mastering the **Go (Golang)** programming language.

---

## 📂 Project Structure

```text
go-lab/
├── cmd/
│   ├── variables/     # Variable declarations, types, zero values, type inference
│   ├── conditions/    # if / else statements, switch cases
│   ├── loops/         # for loops, range iterations
│   ├── functions/     # Functions, multiple return values, named returns
│   ├── collections/   # Arrays, Slices, and Maps
│   ├── pointers/      # Pointers, dereferencing, memory addresses
│   └── structs/       # Structs, methods, and receivers
├── go.mod             # Go module definition
└── README.md          # Documentation
```

---

## 🚀 Getting Started

### Prerequisites
Make sure you have [Go](https://go.dev/dl/) installed (version 1.20 or newer).

### Run any experiment
To run any module, navigate to its directory or run directly from root:

```bash
# Example: Run variables lab
go run ./cmd/variables

# Example: Run functions lab
go run ./cmd/functions
```
